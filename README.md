# SportTrack

Application web progressive de suivi personnel sport et nutrition, pensée pour iPhone.

## Mise en ligne
Déposez le contenu de ce dossier à la racine d'un dépôt GitHub, puis activez GitHub Pages sur `main` et `/(root)`.

## Fonctions
- Journal alimentaire avec bibliothèque de départ et quantités modifiables
- Estimations d'énergie, protéines, glucides et lipides
- Repas favoris
- Enregistrement après la séance : exercices, séries, répétitions et charges
- Journal cardio avec type et durée
- Statistiques simples
- Export / import JSON
- Données stockées localement sur l'appareil

Les données nutritionnelles sont indicatives. Les calories dépensées ne sont pas estimées, car elles varient fortement selon la personne et l'activité. Cette application est un carnet de suivi, pas un outil médical ou un programme de restriction alimentaire.
